# Benchmarking Large Language Models for Cell-Free RNA Diagnostic Biomarker Discovery

### Overview

This repository contains the complete code and data used in the study:

“Benchmarking large language models for cell-free RNA diagnostic biomarker discovery.”

This work is to evaluate whether large language models (LLMs) can identify diagnostically informative gene panels from cell-free RNA (cfRNA) data, and to compare their performance against traditional differential expression approaches and machine learning classifiers.

All analyses—including preprocessing, model training, evaluation, and figure generation—are contained within this repository.

### Code Directory (code/)
#### fullpipeline_res.ipynb (Primary Analysis Pipeline)

This notebook is the central pipeline for the study and performs:

  Data loading from the data/ directory
  Processing of gene panels (LLM-derived and DESeq2)
  Machine learning model training
  Evaluation across 100 random seeds
  Calculation of AUC and accuracy
  Aggregation of results
  Generation of manuscript figures

To reproduce results, run all cells in this notebook sequentially.

#### ai_figures.ipynb (Figure Generation)

This notebook generates publication-ready figures, including:

  Model performance distributions
  Comparisons between LLM-derived and DESeq2 gene panels
  Effects of prompt length (short vs long)
  Cross-model performance comparisons
  Data Directory (data/)

  This directory contains all datasets used in the analysis.

### Gene Panel Files

  These files contain gene panels evaluated in downstream machine learning models.

  Naming convention: <DISEASE>_<MODEL>_<PROMPT_TYPE>_<GENE_COUNT>_<SEEDS>_array.csv

  Example: KD_MISC_3.7sonnet_long_200gene_100seed_array.csv

### Differential Expression Files

  These files contain gene panels generated using DESeq2 for baseline comparisons.

  KD_MISC_DESeq2.csv
  TB_DESeq2.csv
  MECFS_DESeq2.csv

### LLM-Derived Gene Lists

  These contain gene lists directly generated by large language models prior to evaluation.

  Examples:

  KD_gpt_genes.csv
  KD_gemini_genes.csv
  KD_claude_genes.csv

  Disease Contexts Included
    KD_MISC (Kawasaki Disease vs MIS-C)
    TB (Tuberculosis classification)
    MECFS (ME/CFS vs control)

### Aggregated Results Files

  auc_data.rds
  auc_data_full.csv
  fullpipeline_stats.csv
  fullpipeline_all_accuracy.csv
  master_auc.csv

  These contain:

  AUC values across seeds
  Accuracy metrics
  Aggregated results used for statistical analysis and plotting
  Prompt Analysis Files

  Examples:
    shortvs_long_length_stats.csv
    deviation_length_all.csv
    badgenes_data_all.csv

  These quantify:

  Differences between short and long prompts
  Deviations from target gene panel sizes
  Quality of generated gene sets
  Additional Directories
  GSEA preranked inputs/ → inputs for pathway enrichment analysis
  full pipeline/ → intermediate outputs from full pipeline runs
  long prompts/ → outputs from long prompt experiments
  short prompts/short_prompts/ → outputs from short prompt experiments
